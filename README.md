# 🏨 Hostel Management Mobile App

A **full-stack Hostel Management Mobile Application** built using **React Native**, **JavaScript**, and **MongoDB**.  
This app is designed to efficiently manage hostel operations such as student records, room allocation, staff management, and daily activities.


## 📱 Project Overview

The **Hostel Manager App** is an Android-based mobile application developed using **React Native** for the frontend and **JavaScript backend** with **MongoDB** as the database.  
The application is built and tested using **VS Code** and **Android Studio**, and exported as an **APK** for Android devices.


## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 👩‍🎓 Student Management
- 🏠 Room Allocation & Management
- 👨‍🍳 Staff / Kitchen Management
- 📊 Admin Dashboard
- 📱 Mobile friendly UI
- 🔄 Real time Data Handling
- 🗄️ MongoDB Database Integration
